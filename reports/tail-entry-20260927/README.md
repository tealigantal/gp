# 尾盘入场判断交付与真实实验

2026-09-27，当前工作分支实现并验证，未提交、推送或部署。原有用户未提交修改保留。代码已接入 worker、ConversationService、HTTP 和现有页面；本记录不宣称生产容器已经更新。

## 实现与删除

唯一正式路径为 `SinaMinuteProvider → entry_evidence → EntryService → ContractStore.EntryAssessment`。worker 从交易日14:35开始准备当前入选股票，14:57停止确认；聊天按相关股票调用相同入口，页面读取相同评估。相同计划、股票、场景和证据只保存一个正式结果，跨进程去重，有效证据跨场景复用。

删除报价涨跌幅生成盘中分数的 `application/runtime_producer.py`；删除分钟源自动切换、`allow_fallback`、伪造 close×volume 成交额；替换要求用户自行看图的人工清单、中文禁词校验、修复模型回答和固定运行状态前缀。保留原日线评分、排名、不可变计划、午盘原子批次和原有其他有效功能。没有新增尾盘分数、规则建议替代、其他模型或旧结构兼容。

Agent 接收代码计算的15/30分钟变化、最近价格结构、真实VWAP（条件满足时）、相邻15分钟成交量比、同窗口指数表现、计划买入区间和止损事实，生成结构化建议、走势、理由和变化说明。结构化校验限制明确交易事实，原始评分不写回。持仓加仓是独立场景；缺少规模、成本和风险预算时不能伪装为首次建仓许可。

## 14:40／14:50截断评估

使用相同生产证据函数及正式模型评估入口，以历史模式显式保存，不伪装为当前结果。所有计算和摘要之前先截断日期与闭合边界：14:40使用09:35–14:40的44根，14:50使用09:35–14:50的46根，逐条时间和完整证据见 [assessments.json](assessments.json)。实际数据获取时间仍是9月27日，没有回写成9月24日。

| 标的／判断时刻 | 最新价 | 15分钟变化 | 30分钟变化 | 模型走势／建议 | 模型评估链路耗时 |

| 003006 14:40 | 22.57 | -0.3532% | -0.1769% | mixed／wait，暂不入场 | 2015 ms |
| 603268 14:40 | 215.68 | -0.4937% | -0.7592% | weakening／wait，当前不建议入场 | 2297 ms |

以上均仍在样本计划区间内，模型没有因此自动判买。历史实验先取数再评估，表中评估耗时不包含预取的网络耗时；网络耗时独立记录，不能当作现场端到端延迟。生产实时入口的total_ms覆盖取数、证据和模型处理，结束时重新检查时效与14:57边界。

重要边界：使用计划 `plan_a175a3d68bb867852994fe2a`，交易日为9月28日，生成于9月24日17:08:46，晚于目标判断时刻。因此这4次只验证真实分钟特征及入场评估链路，不是当时已经可作出的完整历史决策，不是策略回测。

集中新鲜度规则允许最近闭合边界落后一根：14:40可用14:35，14:50可用14:45；更早数据拒绝。此边界是当前实现约束，尚未得到盘中发布延迟现场验证，不是供应商SLA。失败不会解释成走弱、停牌或沿用上一条可以买。

## 真实模型、多轮与页面

沿用当前DeepSeek配置及 `deepseek-v4-flash`，未改模型或凭据。按[官方工具调用协议](https://api-docs.deepseek.com/guides/tool_calls/)及[思考模式协议](https://api-docs.deepseek.com/guides/thinking_mode/)使用现有客户端，实际历史、绑定计划和工具结果进入上下文。

[dialogues.json](dialogues.json)保留7轮问题、回答和真实工具轨迹：问候、第一只、第二只、重新看、解释之前是否走弱、继续、已有部分仓位加仓。问候只respond；第一只定位003006，第二只和后续定位603268；刷新调用evaluate_entry；变化解释调用read_entry；加仓使用add_position。周末真实时钟下明确未完成当前确认，没有下载全市场或把历史评估当作现在可以买。这证明真实模型理解上下文并调用工具；不证明盘中数据现场可用。

另以7类合成走势测试真实模型：日涨尾弱、日跌修复、持续走强、正常回踩、冲高回落、走强超出区间、混合方向，最终7项通过，强势且区间合适能形成consider_entry，走弱/超区间不买。合成行情仅用于测试，见 [synthetic-model-tests.json](synthetic-model-tests.json)。初次混合方向被模型当作回踩并允许入场，原失败保留于 [synthetic-mixed-initial-failure.json](synthetic-mixed-initial-failure.json)；修正走势语义后完整重跑7类通过，没有反复重跑挑选通过样本。另修正过结构化证据字段范围及最终工具回答引用约束，未用中文禁词或固定回答遮盖失败。

隔离API8011与现有前端5179完成真实浏览器操作：打开推荐卡片，发送“第一只现在能买吗？”，真实模型返回周末无法当前确认；页面保留原日线分数，未显示旧买入结论为当前。截图见 [page.png](page.png)，浏览器无console错误。隔离服务已停止，生产容器未改动。
