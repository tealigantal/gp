# 日K官方停牌事实接入 ExecPlan

## Goal

让已由官方公告明确证明的少数停牌股票完成日K覆盖分母排除，同时保持全市场日K、推荐发布与 Serenity 评分边界独立且 fail closed。

## Scope and non-goals

- 仅修改 `market_runs.db` 的运行账本、日K child worker 和既有日K契约测试。
- 不修改 `history.db`、产品计划/会话、选股算法、Serenity batch/store/3% 契约或公开接口。
- 不把公告采集放入 API、聊天、计划生产者或全市场扫描。

## Milestones

1. [x] 复核两只缺失股票的官方公告、发布时间、PDF 生效日期与交易所记录；确认旧全零现货路径在近似重建分母中被正确拒绝，但没有公告事实入口。
2. [x] 实现独立官方停牌事实收集器，并在普通日K源完成后对不超过十只的残余缺失接入。
3. [x] 给运行账本增加可审计公告证据，并确保后续同日冻结不会把正式排除改回 pending。
4. [x] 修改既有测试（不增文件、不增测试数量）覆盖中断续跑、官方排除、账本证据与日期文本失败关闭。
5. [x] 执行全量验证：编译、既有 5 个日K契约测试和默认 52 测试均通过。
6. [x] 经部署授权后重建 `gp-worker`，真实 worker 先重试日K源，再核验 2026-07-27 的两个残余缺失并完成 run。
