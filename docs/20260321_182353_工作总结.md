## 修复对应真实问题

1) “荐股”成功但文本顺序与卡片不一致：
   - 在提示词中明确“顺序必须跟 items 对齐”，并通过工具结果驱动文本生成；`active_artifact_summary.ordered_symbols` 也提供显式顺序线索。

2) “为什么是这几支”泄露 `<｜DSML｜function_calls>` 且 right_panel 置空：
   - 输出文本净化去除 DSML/函数 JSON；
   - 若本轮没有新面板，回退 `last_right_panel`，避免 UI 置空。

3) “这是什么”报 `symbols_out_of_scope`：
   - 在无当轮 ensure_recommendation 时，校验允许使用 `state.active_symbols`；
   - 同时 layered context 始终注入，确保承接同一 orchestrator 路径。

4) “怎么回事”退化为泛化 onboarding：
   - 每轮都注入 layered turn_context（会话状态、对话足迹、工具轨迹精简摘要），不走“ctx-only 自由发挥”的分叉。

5) `last_right_panel` 写入未存：
   - 已纳入 `_STATE_DEFAULTS` 并通过 `update_state()` 持久化；`get_state()` 兼容旧字段。

## 设计对齐点

- 不引入新库/新服务，继续使用现有 SQLite 的 `session_store` + `event_store`。
- 保持 `/threads/{cid}/items` 只返回用户文本与 `assistant_bundle`。
- 金融事实仅来自工具结果/active artifact；自然承接来自会话记忆与 continuation state。
- 每轮都由同一个 orchestrator 起步（entry tools + full tools），严格工具约束。
