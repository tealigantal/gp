# Research Log

2026-07-28: Read-only live inspection of the second residual run found that `002036` and `002828` had a fresh target-session AkShare/Sina snapshot at 20:34: both had positive previous close and zero price, OHLC, volume and amount; the snapshot was non-fallback, non-stale and session-bound to 2026-07-28. The run remained pending only because a missed 14:57 freeze set `reconstructed_current_universe`, while `_freeze_universe` and `_finalize_same_day_exclusions` incorrectly treated that denominator provenance as a ban on the already strict same-day fact. The 7/25 CNINFO notices must not be extended from their 7/27 start date merely because they state a maximum expected duration; this is an upper bound, not a target-day status. The decision is therefore to restore the existing same-day fact path for current-day reconstructed runs, preserve approximate provenance, immediately re-read persisted daily bars after denominator reconciliation, and keep both historical reconstruction and cross-day announcement inference fail closed.

2026-07-28: A read-only comparison of the live stores separated a stale-publication symptom from a daily-data failure. `history.db` held 2026-07-27 evidence for all 3042 expected symbols, while the current publication referenced a plan for the 2026-07-27 session built with 2026-07-24 evidence. The daily run had completed at 00:35, but `MarketClock` allowed base-plan generation only before midnight or in a later 09:20–09:30 slot. This was a cross-midnight self-healing contract gap, not a wrong fetch and not a database or Serenity fault. The plan window is therefore 15:20 through the target session's 09:30; the UI must identify the old plan as review-only until the new publication exists.

2026-07-28: Read-only CNINFO and exchange probes traced the final 2026-07-27 coverage gap. `002036` record `1225440686` and `002828` record `1225441689` were both pre-open suspension disclosures; their PDF text contained the exact 2026-07-27 open-suspension wording and Shenzhen exchange verification matched each CNINFO announcement ID. The live daily run had instead used a `reconstructed_current_universe` from a stale 2026-07-26 spot snapshot, so the intentionally strict fresh-all-zero spot rule could not apply. Investigation found no database corruption: `OfficialSuspensionEvidence` existed only as generic source/verification components underneath Serenity, while `MarketRunStore` had no way to consume an official no-bar fact. ADR 0015 separates these two contracts without allowing Serenity scoring ownership to leak into daily coverage.

2026-07-28: Deployment exposed an independent Compose ownership defect: `gp-worker` consumed the shared `gp-backend` image but did not itself inherit the `build` declaration, so `docker compose build gp-worker` was a no-op. The build declaration now belongs to the shared backend service definition. A subsequent worker-only rebuild contained the new collector, and the live target run completed with two official suspension facts; no `history.db` rows or complete daily bars were deleted.
