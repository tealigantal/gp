## 公式与冻结政策

`x_j = return_3d_j - 0.003`；按 event_id 去重后以相似度归一化，`G = Σw_j max(x_j,0)`、`L = Σw_j max(-x_j,0)`；按信号日期聚合 W_d，`N = (1/ΣW_d²) × mean(similarity)`。N 仅为评分支持量。

唯一基础分为 `(N*G + 0.5*n0*A0)/(N*(G+L)+n0*A0)`；内部0–1，显示乘100。`expected_net_return=G-L`，不重复扣成本、不再乘上涨概率。有效 G=L（包括全零净收益）得50；不足证据向50收缩；空/缺失/非法日期/非有限值/零权重/无效政策明确失败，不伪装50分。

实际政策：[configs/daily_scoring.json](../configs/daily_scoring.json)。n0=20 是可配置初始政策值，未优化；A0=0.03997941946323374 是共同池平均绝对净收益，全部以小数收益率记录。来源为活动本地 Docker 存储中已提交成熟池：4,000案例、2,145股票、155信号日期；信号2026-01-21～09-09，T+5成熟2026-01-28～09-16。严格使用证据日2026-09-17前已成熟、知识时间2026-09-17T23:01:39.040592+08:00前已首次出现且维护批次已完成的案例。沿用生产最近最多250日期交错取4000共同池，不按候选股票另选。
